# swiperefresh

Swipe to refresh from the top or the bottom of a scrolling layout.

Adapted from Accompanist's deprecated `swiperefresh` module, with the
bottom indicator from google/accompanist#541, which was never merged.
Licensed under Apache 2.0, as the original; each file keeps its notice.

Changes from the original:

- Material 3 instead of Material.
- `SwipeRefreshIndicator` takes an optional `icon`, drawn in place of
  the progress arrow.
